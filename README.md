# Podstawy Sztucznej Inteligencji (Fundamentals of AI) - Labs

This repository contains a set of Jupyter Notebooks for the **Fundamentals of Artificial Intelligence** laboratory course (written in polish) in Computer Science program at the AGH UST. 

The original, unfilled base course material can be found at the official repository: [agh-cs-ai/podstawy-sztucznej-inteligencji](https://github.com/agh-cs-ai/podstawy-sztucznej-inteligencji).

## Contents

- **[Lab 1: Linear and Logistic Regression](lab1/lab_1.ipynb)** - Data preparation, cleaning, scaling, linear/logistic models, cross-validation, and L1/L2 regularization using Scikit-Learn.
- **[Lab 2: Imbalanced Classification and Ensemble Classifiers](lab2/lab_2.ipynb)** - Working with imbalanced datasets, ensemble methods, and explainable AI techniques.
- **[Lab 3: Neural Networks](lab3/lab_3.ipynb)** - Introduction to PyTorch, building Multilayer Perceptrons, gradient descent, and creating training/validation loops.
- **[Lab 4: Convolutional Neural Networks](lab4/lab_4.ipynb)** - Designing and training CNNs for image classification tasks.
- **[Lab 5: Natural Language Processing](lab5/lab_5.ipynb)** - Intrduction to Transformer architectures and the Hugging Face `transformers` library for NLP use cases.
- **[Lab 6: Decision Making](lab6/lab_6.ipynb)** - Algorithms for adversarial search including Minimax, Alpha-Beta Pruning, and Monte Carlo methods.
- **[Lab 7: Recommender Systems](lab7/lab_7.ipynb)** - Building recommender systems using Collaborative Filtering (user/item-based) and Matrix Factorization algorithms.
